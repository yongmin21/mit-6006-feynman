Chapter 1. 알고리즘이란 무엇인가?

컴퓨터에게 “문제를 푼다”는 것은 무슨 뜻일까?

오늘의 문제

1,000만 명의 전화번호부에서 김알고를 찾는다고 하자. 가장 먼저 떠오르는 방법은 앞에서부터 한 명씩 보는 것이다.

def find_phone(people, target):
    for name, phone in people:
        if name == target:
            return phone
    return None

단순하지만 맞다. 알고리즘 설계는 종종 가장 영리한 방법이 아니라 확실히 맞는 방법에서 시작한다.

WHY?

알고리즘은 특정 언어의 코드가 아니라, 입력을 올바른 출력으로 바꾸는 명확한 절차다. 좋은 설명은 세 단계로 이어진다: 풀기 → 증명하기 → 분석하기.

문제를 먼저 정의하라

“리스트에서 큰 값을 찾기”는 모호하다. 최댓값인가, 위치인가, 상위 10개인가? 빈 리스트는 허용하는가?

입력 → 계산 문제 → 출력

예를 들어 최댓값 문제는 “비어 있지 않은 숫자 수열을 입력받아, 모든 원소 이상인 한 원소를 출력한다”라고 정의할 수 있다.

INVARIANT

왼쪽부터 원소를 확인할 때, best는 지금까지 본 원소 중 최댓값이다. 반복이 끝나면 모든 원소를 보았으므로 best는 전체 최댓값이다.

효율성은 입력 크기의 함수다

실행 시간은 컴퓨터와 환경에 따라 달라진다. 대신 입력 크기 n이 커질 때 필요한 작업량이 어떻게 증가하는지 본다.

  • 한 번 훑기: Θ(n)
  • 모든 쌍 비교: Θ(n²)
  • 매번 절반 버리기: Θ(log n)

TRADE-OFF

정렬되지 않은 전화번호부를 한 번 찾는다면 선형 탐색이면 충분하다. 반복해서 찾는다면 정렬이나 해시 테이블을 준비하는 비용이 이득이 될 수 있다.

DON’T USE THIS WHEN

입력이 이미 정렬되어 있고 임의 접근이 가능하다면 선형 탐색은 불필요하다. 이진 탐색으로 후보를 절반씩 줄일 수 있다.

연습문제

  1. 빈 입력에서 위 전화번호 검색 함수는 무엇을 반환하는가?
  2. 최댓값 알고리즘의 불변식을 한 문장으로 설명하라.
  3. 100만 번 검색할 전화번호부라면 어떤 준비를 고려하겠는가?
해설 보기
  1. None을 반환한다.
  2. 지금까지 확인한 범위에서 현재 값이 최댓값이다.
  3. 이름으로 정렬해 이진 탐색하거나 해시 테이블을 구축할 수 있다. 준비 비용과 조회 횟수를 함께 비교해야 한다.
