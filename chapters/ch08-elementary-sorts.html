Chapter 8. Selection Sort / Insertion Sort

카드 더미에서 최솟값을 뽑을까, 손의 정렬된 카드 사이에 새 카드를 끼울까?

학습목표

  • 두 정렬의 불변식과 Θ(n²) 비용을 도출한다.
  • stable과 in-place를 구현 행동으로 설명한다.
  • 입력의 거의 정렬됨과 쓰기 비용에 따라 둘을 선택한다.

오늘의 문제

숫자 카드 [5,2,4,2,1]을 추가 배열 없이 정렬하라. 같은 값의 빨강 2가 파랑 2보다 먼저였다면 그 순서도 유지해야 할까?

Naive baseline · 모든 순열 시험

n!개 배치를 만들고 정렬 여부를 검사하면 Θ(n·n!)이다. 비교에서 얻은 정보를 보존하지 못한다.

병목

한 번 알아낸 “이 부분은 이미 정렬됨”을 다음 단계에서 재사용해야 한다.

아이디어 재발명

Selection: 바닥의 최솟값을 뽑아 앞에 둔다

미정렬 구간에서 최솟값을 찾아 경계와 교환한다. 비교는 많지만 교환은 최대 n−1번이다.

Insertion: 손의 정렬된 카드에 끼운다

새 카드를 왼쪽의 큰 카드들 너머로 이동한다. 거의 정렬된 입력에서는 이동이 적다.

MIT formalization

in-place는 입력 크기에 비례하는 보조 배열 없이 정렬한다는 뜻이다. stable은 같은 키 레코드의 원래 상대 순서를 보존한다는 뜻이다. 아래 Selection은 in-place지만 멀리 swap하여 불안정하고, Insertion은 큰 값만 오른쪽으로 밀어 stable이면서 in-place다.

WHY?

Selection은 최솟값 하나를 확정하고, Insertion은 정렬된 접두사를 한 장 늘린다. 둘 다 루프가 끝나면 정렬 전체가 된다.

INVARIANT

Selection: A[:i]는 가장 작은 i개가 정렬된 구간. Insertion: A[:i]는 원래 첫 i개 원소의 정렬된 순열.

TRADE-OFF

둘 다 최악 Θ(n²). Selection은 Θ(n) swaps, Insertion은 역전 수만큼 이동하며 stable하다.

DON’T USE THIS WHEN

큰 무작위 입력에는 Θ(n log n) 정렬을 쓴다. 다만 작은 하위 배열이나 거의 정렬된 데이터에는 Insertion이 실용적이다.

손으로 추적하기

Python 구현

def selection_sort(a):
    for i in range(len(a)):
        m = min(range(i, len(a)), key=a.__getitem__)
        a[i], a[m] = a[m], a[i]

def insertion_sort(a):
    for i in range(1, len(a)):
        value, j = a[i], i
        while j and a[j - 1] > value:
            a[j] = a[j - 1]
            j -= 1
        a[j] = value

Correctness와 핵심 불변식

Selection은 미정렬 구간 최솟값을 경계에 놓으므로 확정 접두사가 하나 는다. Insertion은 새 값보다 큰 원소만 한 칸 밀고 빈자리에 값을 놓으므로 접두사의 정렬과 원소 보존이 유지된다.

MIT-style 문제

Mechanics

[3,1,2,1]을 두 알고리즘으로 각각 두 단계 추적하라.

Recognition

플래시 메모리처럼 쓰기가 비싼 작은 입력과, 거의 정렬된 입력에 각각 무엇을 택할까?

Invention

Insertion을 내림차순 stable 정렬로 바꾸되 같은 키 순서를 보존하라.

해설 보기
  1. 각 불변식의 경계를 표시하면 된다.
  2. 전자는 Selection의 적은 swap, 후자는 Insertion의 적은 역전 이동이 유리하다.
  3. while 비교를 a[j-1] < value로 바꾼다. 등호에서는 이동하지 않아 안정성이 유지된다.

Feynman Test

두 정렬이 모두 Θ(n²)인데도 실제 선택이 달라지는 이유를 카드 행동으로 설명하라.

빈 종이 테스트

두 불변식, stable/in-place 정의, 비교·swap·역전 수 비용표를 복원하라.

한 장 요약

  • Selection은 최솟값을 선택해 확정한다.
  • Insertion은 정렬 접두사에 새 값을 삽입한다.
  • 안정성과 제자리성은 결과가 아니라 구현의 보장이다.
