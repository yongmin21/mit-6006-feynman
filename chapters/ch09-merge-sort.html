Chapter 9. Merge Sort와 Divide & Conquer

반으로 나누고, 각각을 풀고, 두 정답을 선형 시간에 합친다.

학습목표

  • 두 정렬 배열을 Θ(n)에 merge하고 정확성을 증명한다.
  • 분할정복 구조에서 T(n)=2T(n/2)+Θ(n)을 세운다.
  • 재귀 트리와 Chapter 2의 성장률을 연결해 Θ(n log n)을 설명한다.

오늘의 문제

Insertion Sort의 Θ(n²)을 피하면서 모든 입력을 안정적으로 정렬할 수 있을까?

Naive baseline · 한 장씩 삽입

정렬된 접두사에 n개를 넣으면 역순 입력에서 1+2+…+(n−1)=Θ(n²) 이동이 든다.

병목

큰 정렬 구간 안쪽으로 원소를 반복 이동한다. 이미 정렬된 두 덩어리를 합칠 때는 각 맨 앞만 보면 된다.

아이디어 재발명

  1. Divide: 배열을 반으로 나눈다.
  2. Conquer: 두 반쪽을 재귀적으로 정렬한다.
  3. Combine: 앞 원소가 작은 쪽을 결과에 옮긴다.
T(n) = 2T(n/2) + Θ(n)두 하위 문제선형 merge

MIT formalization

재귀 트리의 레벨마다 모든 하위 문제 크기의 합은 n이므로 비용은 Θ(n)이다. 크기가 n에서 1까지 절반씩 줄어 레벨 수는 Θ(log n). Chapter 2의 “레벨당 비용 × 레벨 수”로 총 Θ(n log n)이다.

n
n/2　 n/2
n/4　 n/4　 n/4　 n/4
… log₂n 레벨, 각 레벨 합 Θ(n)

WHY?

정렬된 두 배열의 최솟값은 둘의 맨 앞 중 하나다. 선택한 앞 원소를 버리고 같은 주장을 반복할 수 있다.

INVARIANT

merge 결과에는 두 입력에서 소비한 원소가 정확히 정렬되어 있고, 결과의 모든 값은 남은 모든 값 이하이다.

TRADE-OFF

항상 Θ(n log n)이고 stable하게 만들기 쉽지만, 배열 구현은 보조 공간 Θ(n)을 쓴다.

DON’T USE THIS WHEN

메모리가 엄격히 제한되거나 아주 작은 배열이면 제자리 Insertion이 단순하다. 연결 리스트는 merge 비용의 장점이 더 크다.

손으로 추적하기

[2,7]과 [1,3,8]을 merge한다. 앞 비교는 (2,1)→1, (2,3)→2, (7,3)→3, (7,8)→7, 남은 8. 결과는 [1,2,3,7,8]이다.

Python 구현

def merge(left, right):
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]

def merge_sort(a):
    if len(a) < 2:
        return a[:]
    m = len(a) // 2
    return merge(merge_sort(a[:m]), merge_sort(a[m:]))

Correctness와 핵심 불변식

기저 배열은 정렬되어 있다. 귀납 가정으로 두 재귀 결과가 정렬되어 있고, merge 불변식이 매번 남은 최솟값을 붙인다. 따라서 결과는 정렬되며 모든 원소를 정확히 한 번 포함한다. 동률일 때 왼쪽을 먼저 골라 안정성도 보존한다.

Complexity

merge는 두 포인터가 총 n번 전진해 Θ(n). 점화식은 T(n)=2T(n/2)+Θ(n), 재귀 트리에는 Θ(log n) 레벨이 있으므로 Θ(n log n) 시간, 배열 복사와 결과에 Θ(n) 보조 공간이 든다.

MIT-style 문제

Mechanics

n=8인 재귀 트리의 레벨별 하위 문제 수, 크기, 총 merge 비용을 적어라.

Recognition

T(n)=2T(n/2)+Θ(1)과 Merge Sort 점화식의 차이를 트리로 비교하라.

Invention

두 정렬 배열에서 중복을 제거한 합집합을 선형 시간에 만들어라.

해설 보기
  1. 1×8, 2×4, 4×2이며 각 merge 레벨 합은 8이다.
  2. 전자는 레벨 비용이 1,2,4,…로 총 Θ(n); 후자는 매 레벨 Θ(n)이라 Θ(n log n).
  3. 작은 앞 값을 택하되 마지막 출력과 같으면 건너뛴다. 두 포인터는 각각 끝까지 한 번 간다.

Feynman Test

왜 재귀 호출이 두 개여도 Θ(2ⁿ)이 아니라 Θ(n log n)인지 재귀 트리로 설명하라.

빈 종이 테스트

merge 추적, 점화식, 레벨당 Θ(n), log n 레벨, 안정성의 <=를 복원하라.

한 장 요약

  • 분할정복은 divide–conquer–combine이다.
  • merge는 정렬된 두 입력을 Θ(n)에 합친다.
  • Θ(n) × Θ(log n)=Θ(n log n).
