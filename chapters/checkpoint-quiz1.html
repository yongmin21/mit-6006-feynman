CHECKPOINT · CHAPTER 3–11

Quiz 1 Checkpoint

답을 펼치기 전에 정의 → 알고리즘 → 정확성 → 비용 순서로 종이에 완성하라.

사용법과 학습목표

  1. 60분 타이머를 켜고 외부 자료 없이 푼다.
  2. 각 답에 모델·불변식·복잡도를 쓴다.
  3. 채점 뒤 틀린 장의 빈 종이 테스트로 돌아간다.

MIT 원문을 복제하지 않고 Quiz 1의 학습 목표와 풀이 습관을 한국어 문제로 재구성했다.

1구역 · 개념 회상

1. 인터페이스와 구현

Sequence와 Set의 대표 연산을 세 개씩 쓰고, 같은 배열이 두 인터페이스를 어떻게 다르게 구현하는지 설명하라.

해설 보기

Sequence는 get_at/set_at/insert_at, Set은 find/insert/delete 등이 핵심이다. 배열의 위치 접근은 Θ(1)이지만 임의 key 검색은 Θ(n)이다. 요구 연산을 먼저 정해야 한다.

2. 비용 모델

최악 Θ(n)인 dynamic-array append를 분할상환 Θ(1)이라 부를 수 있는 이유를 써라.

해설 보기

두 배 확장의 복사량은 1+2+4+…<2n. 임의의 n회 append 총비용이 Θ(n)이므로 연산당 분할상환 Θ(1)이다. 확률적 평균이 아니다.

3. 정렬 속성

stable, in-place, comparison sort를 각각 한 문장으로 정의하라.

해설 보기

stable은 동률의 상대 순서 보존, in-place는 입력 비례 보조 공간을 쓰지 않음, comparison sort는 키의 대소 비교로 순서를 알아내는 정렬이다.

2구역 · 자료구조/정렬 선택

4. 워크로드 표

(a) 인덱스 조회가 대부분, (b) 알려진 노드 뒤 삽입이 대부분, (c) 끝 append와 조회가 섞인 경우 Array/Linked List/Dynamic Array 중 선택하고 비용을 써라.

해설 보기

(a) Array Θ(1) 접근, (b) Linked List Θ(1) 링크 변경(노드를 이미 안다는 조건), (c) Dynamic Array Θ(1) 접근·분할상환 Θ(1) append.

5. 정렬 선택

(a) 거의 정렬된 작은 레코드, 안정성 필요, (b) 임의 객체 큰 입력, 최악 보장, (c) [0,n²) 정수 키에 맞는 정렬을 선택하라.

해설 보기

(a) Insertion Sort, (b) Merge Sort, (c) base n의 2-pass Radix Sort. 선택 조건까지 말해야 한다.

6. 정렬할까?

고정 배열에 range query q개가 온다. 매번 스캔과 사전 정렬 전략의 비용을 비교하고 기준을 제시하라.

해설 보기

스캔 Θ(nq), 정렬 Θ(n log n+q log n+K). q가 충분히 크고 출력 K가 같다면 정렬 전처리가 이득이다.

3구역 · 손으로 추적

7. 동적 배열

초기 capacity 1에서 A–I를 append할 때 resize 시점, 새 capacity, 총 복사 수를 표로 그려라.

해설 보기

길이 1,2,4,8에서 resize하여 capacity 2,4,8,16. 복사 수는 1+2+4+8=15.

8. Merge와 점화식

[2,5,9]와 [1,5,7]을 stable merge하고 포인터 이동을 표시하라. Merge Sort 점화식도 써라.

해설 보기

[1,2,5(left),5(right),7,9]. 동률에서 왼쪽을 먼저 골라 stable. T(n)=2T(n/2)+Θ(n)=Θ(n log n).

9. Radix

[31,22,13,21]을 base 10 LSD Radix로 각 pass 뒤 배열을 써라.

해설 보기

일의 자리 뒤 [31,21,22,13], 십의 자리 뒤 [13,21,22,31]. 각 pass가 stable해야 한다.

4구역 · 종합 설계

10. 중복과 최근접

정수 n개에서 중복 존재 여부와 가장 가까운 서로 다른 두 값의 차이를 함께 구하는 알고리즘을 설계하고 증명·분석하라.

해설 보기

정렬 후 인접 쌍을 한 번 스캔한다. 같은 인접값이면 중복, 양수 차이의 최솟값이 답이다. 어떤 비인접 쌍 사이에도 인접 간격이 있어 더 작거나 같은 후보가 존재한다. Θ(n log n) 시간.

11. 하한의 경계

비교 정렬 Ω(n log n)을 설명한 뒤 0≤key<n인 레코드를 stable Θ(n)에 정렬하라.

해설 보기

n! 잎의 이진 decision tree 높이가 Ω(n log n). 뒤 문제는 키를 인덱스로 쓰는 stable Counting Sort Θ(n+u)=Θ(n)이므로 비교 모델 밖이다.

12. 로그 시스템

시간순 append, ID 정확 검색, 특정 시간 범위 출력이 모두 필요한 시스템의 최소 설계를 제안하라.

해설 보기

시간순 Dynamic Array로 append와 range 경계 검색을 제공하고, ID 검색용 hash index를 별도로 둔다. 단일 구조가 모든 연산을 최적으로 만들려 하지 않는다. 공간 Θ(n), append는 인덱스 갱신 포함 기대·분할상환 Θ(1), 시간 범위는 Θ(log n+k).

Feynman Test

12문제 중 하나를 골라 문제 정의, 선택한 표현, 불변식, 정확성, 복잡도, 쓰지 말아야 할 조건까지 3분 동안 설명하라.

빈 종이 테스트

자료구조 연산표, 정렬 속성표, Merge 재귀 트리, comparison 하한, Counting/Radix 비용식을 한 장에 복원하라.

한 장 요약

  • 인터페이스와 워크로드가 구현 선택보다 먼저다.
  • 정렬은 반복 질의를 단순하게 하는 중간 표현이다.
  • 불변식으로 정확성을, 비용 모델과 입력 가정으로 성능을 말한다.

다음 장 연결
