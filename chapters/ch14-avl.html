Chapter 14. AVL Tree — 나쁜 트리는 스스로 고친다

BST의 순서는 그대로 두고 높이 차이만 국소적으로 고친다.

학습목표

  • 불균형 BST가 Θ(n)으로 실패하는 입력을 보인다.
  • AVL balance invariant와 single/double rotation을 추적한다.
  • insert/delete 뒤 O(log n) 복구와 연산 보장을 설명한다.

오늘의 문제

정렬된 key가 들어와도 search/insert/delete 최악 O(log n)을 보장하라.

Naive baseline과 실패

1,2,3,4,5를 plain BST에 넣으면 모두 right child가 되어 h=4다. n개면 h=n-1이고 search는 Θ(n)이다.

병목

BST invariant는 순서만 말하고 모양은 제한하지 않는다. 매 갱신 뒤 subtree 높이 차이를 제한해야 한다.

아이디어 재발명

각 노드에 height를 저장하고 balance = height(left)-height(right)를 계산한다. |balance|≤1을 유지한다. 3→2→1처럼 같은 방향으로 무너지면 right rotation, 3의 left 1의 right 2처럼 꺾이면 left rotation 후 right rotation한다.

    3           2
   /    right  / \
  2     ───→  1   3

1

MIT formalization

AVL node는 height augmentation을 가진 BST다. 회전은 in-order 순서를 보존하면서 O(1)개의 link와 height만 바꾼다. 삽입은 leaf까지 O(h), ancestor를 올라가며 최초 불균형을 회전한다. 삭제는 여러 ancestor가 연속으로 불균형해질 수 있어 root까지 복구한다.

WHY?

높이 h인 AVL의 최소 노드 수는 N(h)=1+N(h-1)+N(h-2)라 Fibonacci처럼 증가한다. 따라서 n≥φ^h, 즉 h=O(log n).

INVARIANT

BST ordering과 모든 노드의 정확한 height, 그리고 |height(left)-height(right)|≤1을 동시에 유지한다.

TRADE-OFF

최악 O(log n)을 얻는 대신 노드마다 height와 갱신당 회전·metadata 갱신 비용을 낸다.

DON’T USE THIS WHEN

exact lookup만 필요한 hash workload, 쓰기보다 순차 읽기가 압도적인 정적 데이터, 또는 구현 단순성이 최우선일 때.

손으로 추적하기

3,1,2 삽입: 2는 1의 right. 3에서 balance=+2이고 left child는 right-heavy다. 1을 left rotation한 뒤 3을 right rotation하여 root 2, children 1·3이 된다.

Python 의사코드

def update(x):
    x.height = 1 + max(height(x.left), height(x.right))

def rotate_right(z):
    y = z.left
    z.left, y.right = y.right, z
    update(z); update(y)
    return y

def rebalance(x):
    update(x)
    if height(x.left) - height(x.right) == 2:
        if height(x.left.left) < height(x.left.right):
            x.left = rotate_left(x.left)
        return rotate_right(x)
    if height(x.right) - height(x.left) == 2:
        if height(x.right.right) < height(x.right.left):
            x.right = rotate_right(x.right)
        return rotate_left(x)
    return x

Correctness와 핵심 불변식

Right rotation 전 in-order가 A,y,B,z,C라면 뒤에도 A,y,B,z,C이므로 BST 순서를 보존한다. 회전 후 아래 노드부터 height를 다시 계산한다. 적절한 single/double rotation은 불균형 노드의 두 subtree 높이 차이를 ≤1로 돌리고 다른 subtree의 내부 invariant는 건드리지 않는다.

MIT-style 문제

Mechanics

30,20,10과 30,10,20 삽입에서 필요한 회전을 각각 그려라.

Recognition

height를 매번 subtree 순회로 계산하면 왜 보장이 무너지는가?

Invention

삭제가 삽입과 달리 여러 ancestor를 고쳐야 하는 예를 설명하라.

해설 보기
  1. 첫째는 30 right rotation, 둘째는 10 left 후 30 right.
  2. 각 ancestor에서 Θ(subtree size)를 써 한 갱신이 Θ(n) 가능. height를 O(1)에 갱신해야 한다.
  3. 삭제로 subtree 높이가 1 줄면 parent 복구 후 그 subtree 전체 높이도 줄 수 있어 위쪽 불균형이 이어진다.

Feynman Test

회전이 BST 순서를 바꾸지 않는데도 높이는 고치는 이유를 in-order sequence로 설명하라.

빈 종이 테스트

LL/LR/RR/RL 네 경우, balance 식, Fibonacci 높이 논증을 복원하라.

한 장 요약

  • AVL = BST ordering + height augmentation + balance invariant.
  • 회전은 순서를 보존하고 모양만 국소 변경한다.
  • h=O(log n)이므로 Set 연산이 최악 O(log n)이다.

다음 장 연결

height처럼 subtree의 답을 저장하면 순위·구간 집계도 빠르게 만들 수 있다.
