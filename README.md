# MIT 6.006 Feynman 교재

MIT OpenCourseWare의 **6.006 Introduction to Algorithms**를 따라가며, 핵심 개념을 한국어로 다시 설명하고 직접 설명해 보는 연습을 제공하는 개인 학습 교재입니다.

## 원칙

- MIT OCW의 강의·문제·해설을 저장소에 직접 복제하지 않습니다.
- 공식 원문은 링크로 안내하고, 본문과 연습은 한국어로 재구성합니다.
- HTML과 CSS만 사용해 PC·태블릿·휴대폰에서 읽고 인쇄할 수 있게 합니다.

## 구성

- `index.html`: 목차와 학습 경로
- `chapters/`: 장별 교재
- `assets/css/book.css`: 공통 스타일
- `references/`: MIT OCW 공식 자료 링크

현재 Chapter 1 원형을 시작점으로 두고, 같은 형식으로 Chapter 2–40을 확장할 예정입니다.
